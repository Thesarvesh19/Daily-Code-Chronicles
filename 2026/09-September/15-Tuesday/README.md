# LeetCode 2472 - Maximum Number of Non-Overlapping Palindrome Substrings

## Problem

Given a string `s` and an integer `k`, find the maximum number of non-overlapping palindromic substrings of `s` such that each palindrome has a length of at least `k`.

A substring is a palindrome if it reads the same forwards and backwards.

**Input:**
```text
s = "abaccdbbd"
k = 3
