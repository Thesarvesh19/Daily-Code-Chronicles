# LeetCode 1477 - Find Two Non-overlapping Sub-arrays Each With Target Sum

## Problem

Given an array of integers `arr` and an integer `target`, find two non-overlapping subarrays such that the sum of each subarray is equal to `target`.

Return the minimum possible sum of the lengths of the two subarrays.

If no such pair exists, return `-1`.

## Example

### Input

```text
arr = [3,2,2,4,3]
target = 3
