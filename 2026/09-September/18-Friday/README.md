# LeetCode 1520 - Maximum Number of Non-Overlapping Substrings

## Problem

Given a string `s` of lowercase English letters, return a list of the **maximum number of non-empty substrings** of `s` such that:

- The substrings do not overlap.
- If a character occurs in a substring, then **all occurrences** of that character must be inside the substring.
- The substrings can be returned in any order.

If there are multiple valid answers, any one of them is acceptable.
