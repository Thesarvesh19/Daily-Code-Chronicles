# LeetCode 2996 - Smallest Missing Integer Greater Than Sequential Prefix Sum

## Problem

You are given a 0-indexed array of positive integers `nums`.

Consider the longest sequential prefix of `nums`, where each element after the first is exactly `1` greater than the previous element.

Let `sum` be the sum of all elements in this sequential prefix.

Return the smallest integer greater than or equal to `sum` that does not occur in `nums`.
